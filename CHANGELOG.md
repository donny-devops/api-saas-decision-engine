## [0.1.0] - 2026-11-25

### Added
- Initial driver-based financial model for API SaaS
- HTTP API with OpenAPI 3.1 specification
- MCP server
- CLI with scenario, sensitivity, goal-seek, Monte Carlo, and agent ask commands
- Interactive dashboard
- Async DAG engine and declarative pipelines
- Multi-agent mesh with master agent and A2A support
- Post-quantum cryptography hybrid chains (ML-KEM-768 + X25519, ML-DSA-65 + Ed25519)
- Business credit platform (intake, documents, foundation, credit builder, funding match, strategy)
- Policy guardrails and pricing decision pack
- Secret scanning, GitHub Actions CI, and security documentation
- Zero npm dependency design (Node ≥ 22.5)
